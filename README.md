## Перегляд

Сайт: https://veyotscaled.github.io/lev-garazh-lviv/

На GitHub файли сайту розташовані в корені репозиторію: відкрити `index.html` або запустити `python -m http.server 4173`. GitHub Pages публікує гілку `main`, папку `/ (root)`.

У локальному робочому каталозі файли розташовані в `dist`: відкрити `dist/index.html` або запустити `python -m http.server 4173 --directory dist`.
